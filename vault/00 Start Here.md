# Limpa's Breakfast: project memory

Open this folder (`vault/`) as an Obsidian vault. Claude reads it at the start of each session (see `CLAUDE.md` in the repo root). **Update the notes below whenever something is decided, built or reported.**

- [[Product]] what it is, who plays it, where it lives
- [[Architecture]] files, how the UI and engine work
- [[Game Rules Summary]] the rules that matter for code (full text: `docs/RULES.md`)
- [[Computer Players]] bots, tuning, results
- [[Online Rooms]] PeerJS rooms, buzzer, codes
- [[UX Decisions]] layout and gameplay choices, and why
- [[Design System]] the one look: tokens, type, components, rules for older players
- [[Tester Feedback]] what real players said, and status
- [[Workflow]] git/PR/test habits and traps
- [[Game Records]] recording games and learning from how people play; report in [[Human Play Insights]]
- [[Open Items]] what is next
- [[Changelog]] merged PRs in order
